귀살대 액션 · ONI HUNTER

달빛도 닿지 않는 방 안, 오니가 도사린다. 살아서 가족 곁으로 돌아가야 한다.

📖

게임 설명

방향키(WASD/↑↓←→)나 화면 드래그, 또는 D패드로 자유롭게 움직인다. 스페이스바(모바일은 화면의 "베기" 버튼)로 바라보는 방향을 향해 칼을 휘두른다. 방 안의 오니를 모두 쓰러뜨리면 오른쪽 출구가 열리고, 그곳에 도착하면 스테이지 클리어다. 바닥의 아이템은 가까이 다가가면 자동으로 줍는다. 하트가 0이 되면 1부 첫 스테이지부터 다시 시작한다.

⚙️
