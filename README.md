# 오니 사냥꾼 (Kimetsu Action)

귀멸의 칼날 세계관을 모티브로 한 실시간 액션 브라우저 게임. 미로가 아니라 열린 방을 자유롭게
돌아다니며 오니를 실시간으로 베어 넘긴다. `stranger-mazes` 프로젝트의 화면 구조(메뉴/설정/캐릭터
선택/스테이지 소개)를 그대로 재사용하고, 실제 게임 화면(이동·전투·적 AI)은 완전히 새로 만들었다.

## 🔗 플레이하기

**(배포 후 채워짐)** — GitHub Pages, `docs/index.html`을 서빙. `web/index.html`을 수정한 뒤
`docs/index.html`에도 복사하고 커밋·푸시해야 배포본에 반영된다.

## 게임 방식

- **이동**: 방향키/WASD, 화면 드래그(가상 조이스틱), 또는 모바일 D패드로 자유롭게 이동.
- **전투**: 스페이스바(또는 화면의 "베기" 버튼)로 바라보는 방향의 부채꼴 범위를 벤다. 오니는
  플레이어에게 다가와 짧은 예비 동작(붉은 테두리 경고) 후 공격한다.
- **목표**: 방 안의 오니를 모두 쓰러뜨리면 오른쪽 출구가 열린다. 출구에 도착하면 스테이지 클리어.
- **아이템**: 바닥의 아이템은 가까이 다가가면 자동으로 줍는다 (회복/가속/공격력 버프/광역 피해/영구
  공격력 증가).
- **저장**: 계정 없이 브라우저 localStorage에 스테이지 경계(체크포인트) 단위로 자동 저장된다.

## 캐릭터

탄지로(포기를 모르는 의지: 치명타를 1회 견뎌냄) · 네즈코(혈귀술 폭주: 스테이지 첫 공격 필살)
· 이노스케(야성의 맷집: 피격 25% 확률로 무효화) · 기유(물의 호흡: 사거리 +30%)
· 시노부(독의 지식: 공격에 고정 피해 추가) · 젠이츠(벽력일섬: 공격 속도 +30%)

## 스테이지 (1부)

최종선별 후지산(튜토리얼) → 아사쿠사 거리 → 무한열차 → 요시와라 유곽 → 무한성(보스)

## 폴더 구조

```
web/index.html   -- 실제 게임 (Canvas 2D, 프레임워크 없음)
docs/index.html  -- GitHub Pages가 서빙하는 사본 (web/index.html과 반드시 동일하게 유지)
```

## 알려진 한계

- 실시간 전투 밸런스(적 체력/공격 속도/플레이어 이동 속도 등)는 상수로 하드코딩되어 있고 실제
  플레이 테스트 없이 짠 초기값이라, 너무 쉽거나 어려우면 숫자를 조정해야 한다.
- 캐릭터/오니/아이템은 실제 애니메이션 아트가 아니라 Canvas로 직접 그린 단순한 도형(원+뿔 모양)
  이다.
- 중간 저장은 스테이지 시작 시점 기준이라, 스테이지 도중 상태(적 위치/체력)는 저장되지 않는다.
